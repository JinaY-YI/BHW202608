# EMS 主站（学生 B）报文格式参考

> 供学生 A（电网模拟器）核对用。本端严格按《变量字典与通信协议-修订版V3.md》实现。
> 每条报文为 JSON、UTF-8 编码、以换行符 `\n` 结尾。

## 一、通用报文头部

所有报文统一 6 个字段：

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `msg_id` | string（纯数字） | 唯一 ID，时间戳(ms)，单调递增，**无字母无连字符** |
| `timestamp` | int（秒） | 发送时刻 Unix 时间戳 |
| `src` | string | 本端固定 `"ems"` |
| `dst` | string | 固定 `"grid_simulator"` |
| `type` | string | 报文类型，见下表 |
| `data` | object | 具体数据 |

## 二、本机发出的报文（EMS → 电网模拟器）

### 1. hello —— 连接握手
```json
{"msg_id": "1788766887628", "timestamp": 1788766887, "src": "ems", "dst": "grid_simulator", "type": "hello", "data": {"role": "ems", "reset_seq": true}}
```

### 2. param_query —— 设备参数查询
```json
{"msg_id": "1788766887629", "timestamp": 1788766887, "src": "ems", "dst": "grid_simulator", "type": "param_query", "data": {}}
```

### 3. yc_yx_request —— 遥测/遥信增量请求（每 1 秒）
```json
{"msg_id": "1788766887630", "timestamp": 1788766887, "src": "ems", "dst": "grid_simulator", "type": "yc_yx_request", "data": {"last_seq": 0, "need_retransmit": false}}
```
- `last_seq`：本端已收到的最大序号（首次连接为 0）；
- `need_retransmit`：序号跳变时置 `true`，请求全量补传。

### 4. command —— 调度指令下发（仅遥调，闭环模式，设定值变化时）
```json
{"msg_id": "1788766887631", "timestamp": 1788766887, "src": "ems", "dst": "grid_simulator", "type": "command", "data": {"commands": [{"cmd_type": "remote_adjust", "target": "wtg_power", "value": 49.86}, {"cmd_type": "remote_adjust", "target": "diesel_power", "value": 5.0}]}}
```
- `cmd_type` 固定 `"remote_adjust"`；
- `target` 仅两种：`"wtg_power"`、`"diesel_power"`；
- `value` 为数字（float），单位 kW。

### 5. heartbeat —— 心跳（每 5 秒）
```json
{"msg_id": "1788766887632", "timestamp": 1788766887, "src": "ems", "dst": "grid_simulator", "type": "heartbeat", "data": {}}
```

## 三、本机期望接收的报文（电网模拟器 → EMS）

### hello_ack
```json
{"msg_id": "...", "timestamp": 1788766230, "src": "grid_simulator", "dst": "ems", "type": "hello_ack", "data": {}}
```

### param_notify（全量设备参数）
```json
{"msg_id": "...", "timestamp": 1788766230, "src": "grid_simulator", "dst": "ems", "type": "param_notify", "data": {"cut_in_wind": 3.0, "cut_out_wind": 25.0, "rated_wind": 12.0, "rated_power": 50.0, "diesel_max": 80.0, "diesel_min": 5.0}}
```

### yc_yx_response（增量/变位，seq 递增）
```json
{"msg_id": "...", "timestamp": 1788766231, "src": "grid_simulator", "dst": "ems", "type": "yc_yx_response", "data": {"seq": 1, "retransmit": false, "yc": {"wind_speed": 12.79, "load_power": 59.02, "wtg_power": 0.0, "diesel_power": 59.02}, "yx": {"wtg_status": 0, "diesel_status": 1}}}
```

### command_response
```json
{"msg_id": "...", "timestamp": 1788766233, "src": "grid_simulator", "dst": "ems", "type": "command_response", "data": {"result": "success", "failed_commands": [], "executed_seq": 2}}
```

### heartbeat
```json
{"msg_id": "...", "timestamp": 1788766235, "src": "grid_simulator", "dst": "ems", "type": "heartbeat", "data": {}}
```

## 四、联调排查要点

1. **`msg_id` 是纯数字字符串**，本端已保证单调递增、无连字符（`1788766887628` 而非 `…-1`）。请学生 A 侧确认没有把 `msg_id` 强转成整数以外的处理。
2. 本端只下发 `cmd_type: "remote_adjust"`（遥调），不下发启停遥控；`target` 只有 `wtg_power`/`diesel_power`。
3. 若学生 A 侧仍“收不到 command”，请在其接收端打印原始报文，重点确认：是否收到 `type=="command"`、`data.commands` 能否解析。
